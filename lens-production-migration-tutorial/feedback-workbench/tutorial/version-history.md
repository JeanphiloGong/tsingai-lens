# Lens 生产教程版本阅读路径

| 版本 | 从哪里开始 | 生产能力 | 下一版压力 |
| --- | --- | --- | --- |
| P1 | 当前 Lens Chat 基线 | 反馈 -> 分析任务 -> 候选案例 | 用户还不能确认问题和证据 |
| P2 | P1 已生成案例 | 读取用户可理解的证据覆盖 | 仍缺人工确认 |
| P3 | P2 工作台 | 保存 Annotation 和 digest | 标注还没有准入决定 |
| P4 | P3 当前标注 | 追加 ReviewDecision | 仍需冻结发布内容 |
| P5 | P4 有效审核 | DatasetSnapshot 与三种 JSONL | 需要离线实验验证 |
| P6 | P5 冻结快照 | 基线、训练和留出评测 | 是否进入产品需要另行决策 |

每版都从上一版已验证的 Lens 工作区继续。版本名表达可观察的生产行为，不代表旧 nano 仓库的提交或独立代码状态。教程正文已经集中到统一迁移仓库，生产代码仍需按 P1–P6 在 Lens 仓库逐版实现和提交。
